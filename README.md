# Cladle（クレードル）

和名で遊ぶ、動物の系統あてゲームです。推測した動物と正解の「最も近い共通祖先」をたどって、今日の動物を当てます。

- 遊ぶ：https://cladle.github.io/cladle/
- 成績はお使いのブラウザに保存されます。

## ファイルの構成

このリポジトリが Cladle の正本です。ここを直して main に入れると、数分で公開ページに反映されます。

| ファイル | 中身 |
| --- | --- |
| `index.html` | 画面の骨組み（タブ・入力欄・系統樹を描く場所） |
| `css/style.css` | 見た目（色・文字・余白） |
| `js/core.js` | 共通の道具、データから系統樹を組み立てる `build()`、共通祖先を探す `path()` と `lca()` |
| `js/daily.js` | 出題：今日の動物とフリーの種の選び方 |
| `js/game.js` | 推測の判定 `guess()`、成績、ヒント |
| `js/board.js` | 系統樹の描画 `treeHTML()`、正解後の結果、共有テキスト |
| `js/share.js` | 共有された問題のリンク |
| `js/input.js` | 入力の補完候補 |
| `js/zukan.js` | 詳細シートと図鑑 |
| `js/texts.js` | データ欄の文章 |
| `js/howto.js` | 遊び方の文章と、例題の再生 |
| `js/main.js` | 画面の切り替えと起動、データの読み込み |
| `data*.json` | 収録データ（生成物。手で直さない） |
| `tools/build_data.py`, `tools/data_more.py` | 収録データの正本。ここから `data-<版>.json` を作る |
| `tools/hard/` | ゲキムズのデータの作り方（`tools/hard/README.md`） |
| `tools/check.py` | 公開前の確認（送るたびに GitHub が自動で動かす） |
| `docs/SCHEMA.md`, `docs/SOURCES.md` | データの形式と、名前の出典 |

JavaScript は上の表の順に読み込まれます。後のファイルは、前のファイルで作った関数や変数をそのまま使えます。

## 直し方

### 画面の文章・見た目・動き

1. GitHub でこのリポジトリを開き、キーボードの `.`（ピリオド）を押す。ブラウザの中でエディタが開く。
2. 直したいファイルを開いて書き換える（データ欄の文章なら `js/texts.js`、遊び方なら `js/howto.js`、色なら `css/style.css`）。
3. 左の「ソース管理」から、何を直したかを一言書いてコミットする。

### 収録種と、種・節目の説明

`data*.json` は直接直さず、`tools/data_more.py` に書き足してから `python3 tools/build_data.py data-<版>.json` で作り直します。直接直すと、次に作り直したときに元に戻ります。

- 説明文だけを直すときは版番号を上げず、公開中と予約中の `data-*.json` に同じ直しを反映する。版番号は今日の動物の選び方に入っているので、上げると並びが全部変わる。
- 種・節目・知名度を増減するときは版番号を上げ、新しい `data-<版>.json` を作り、今いちばん新しい版の `meta.next` に開始日とファイル名を書く（予約式の切り替え）。

送るたびに `tools/check.py` が動き、予約のファイルがそろっているか、`data_more.py` と最新のデータが食い違っていないかを確かめます。結果はリポジトリの「Actions」タブで見られます。

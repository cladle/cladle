# ゲキムズのデータの作り方

ゲキムズの `data-hard-*.json` は、本家のデータに、魚・爬虫両生類・海や陸の無脊椎動物・陸の生き物を足して作ります。中心は `merge_hard.py` です。

## 自分で直せるファイル

| ファイル | 中身 |
| --- | --- |
| `hard_facts.tsv` | ゲキムズだけの種の一言説明。1行1種で、学名・和名・説明・出典をタブで区切る |
| `hard_only.json` | 本家に入れず、ゲキムズだけに入れる種。`place` に、入れる場所の節目（科・目など）を下から順に書く |
| `hard_tiers.tsv` | ゲキムズだけの種の知名度（1〜4）の上書き。学名・和名・tier をタブで区切る（一覧ページの案を表にしたもの） |
| `insect_taxa.json` | 昆虫の目・科の並び（Catalogue of Life）と和名（環境省1997、無ければ Wikidata・GBIF・iNaturalist の多数決）。`insect_taxa.py` が作る。目より上の置き場所は `insect_taxa.py` の `ORDER_UNDER` に書く |
| `bird_taxa.json` | 鳥の目・科・属の並びと和名（日本鳥類目録改訂第8版）。`osj_birds.py` が目録の掲載鳥類リスト（Excel）から作る。目より上の置き場所は `osj_birds.py` の `ORDER_UNDER` に書く |
| `fixes.tsv` | 和名・学名の直し（標準和名リストなどと照らした結果） |
| `insects_refs.tsv` | 照合できなかった昆虫の和名の出典論文 |
| `clade_desc.tsv` | ゲキムズ・番外編だけの節目（目より上）の説明。学名・階級・説明・出典をタブで区切る。説明には、その群の特徴と、近縁の群との違いを書く。見た目で分けられない群は「遺伝子の解析でまとまる」と書く。直したら `apply_clade_desc.py` で今の版と予約中の版の data-*.json に書き込む（文だけの直しなので版は上げない） |
| `move_into.py` | `merge_hard.py` の MOVE_INTO（属や科の置き場所の直し）を、作り直しをせずに出来上がった data-*.json に当てる。木の形が変わるので、当てるのは新しく作る予約版だけにする |

説明や出典は、学術的に確かめられるものだけを書きます。

## リポジトリに置いていない材料

次のファイルは外部のデータベースやリストから取ってきたデータそのものなので、このリポジトリには置かず、Claude のプロジェクトのフォルダ（`metazoa-guess-ja/tools/hard/cache/`）に置いています。データを丸ごと同梱しない、という方針のためです。

- `hard_vert.json`：魚・爬虫両生類（`build_hard.py` が日本産魚類全種目録と爬虫両棲類学会の標準和名リストから作る）
- `col.tgz`：Catalogue of Life の日本語名
- `worms.tgz`：WoRMS の日本語名
- `land.json`：陸の生き物（`build_land.py` が環境省の対象種一覧と Japan Spider Catalog から作る）
- `clade_ids.json`：前回作ったときの節目の id（id が変わっていないかの確認用）

そのため、ゲキムズの作り直しは今のところ Claude が行います。上の表のファイルを直して main に入れたら、作り直しを頼んでください。

## 作り直し

本家・ゲキムズ・魚編・鳥編・昆虫編は、`tools/build_all.py` で1回にまとめて作り直します（中で `merge_hard.py` と各編の `make_*.py` を動かします）。本家の種や説明を直した PR でも、ゲキムズの表を直した PR でも、同じ PR の中でこれを動かします。

```
python3 tools/build_all.py            # 何が変わるかを見るだけ
python3 tools/build_all.py --write    # data-*.json に書く
python3 tools/build_all.py --write --new hard=hard-0.3.13@2026-11-05   # 新しい版を作って予約する
```

- 文だけの違い（和名・説明・別名など）は、今の版にも予約中の版にも入れます。版は上げません。
- 種・節目・知名度の違いは、まだ始まっていない予約版だけを差し替えます。予約版が無いか、もう始まっているときは止まるので、`--new` で新しい版を作ります。
- 本家で作った節目の外に、ゲキムズの同じ群が残っていると知らせます（例：本家でクモ目の下に Araneoidea を作ったのに、ゲキムズのクモの科がクモ目の直下に並んだまま）。本家の木を変えたら、ゲキムズの群も同じように振り分けます（`merge_hard.py` の MOVE_INTO など）。

切り替わったあとは中身を `data-hard.json` に写し、`data-hard-<版>.json` は消します（今まで通り）。

## 出題の重み（実際の種数）

ゲキムズの門と綱、鳥編・昆虫編の目は、収録数ではなく実際の種数（`tools/real_counts.json`）で選びます。ゲキムズの門と各編の目は種数の平方根に比例させて、種数の少ない群も出るようにしています（綱は種数そのまま）。魚編は日本の魚の全種が入っているので、収録数を種数として目を平方根で選びます。新しい門・綱・目の種を足したら、作り直す前に `python3 tools/real_counts.py` を動かして数を足します（控えにある群は問い合わせません）。足し忘れると `tools/check.py` が知らせます。同じ群に種を足すだけなら何もしなくてよく、群の中の割り振りは自動で変わります。

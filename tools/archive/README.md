# 台帳を作る前の作り方（今は使わない）

2026-11-02 に全種の台帳（`tools/ledger/`）を正本にするまで、データはここのファイルから作っていました。

- `build_data.py`・`data_more.py`・`clade_desc_main.tsv`・`gbif_keys.json`：本家（ふつうモード）の正本だったもの
- `hard/`：ゲキムズの作り方。`merge_hard.py` が本家に外部データ（Catalogue of Life・WoRMS の日本語名、日本産魚類全種目録、爬虫両棲類の標準和名リスト、環境省の対象種一覧、Japan Spider Catalog）の種を足していた（`hard/README.md`）
